Tentang Saya

Full-Stack Web Developer & Mahasiswa Sistem Informasi

Saya adalah mahasiswa Sistem Informasi yang berfokus pada pengembangan web full-stack. Saya merancang dan membangun antarmuka modern yang responsif, mengintegrasikan arsitektur sistem, dan mengolah data menjadi eksplorasi yang interaktif — seluruh karya saya terhubung langsung ke deployment live di TillRea.

.

Spesialisasi & Tech Stack Inti

Spesialisasi saya ada pada pengembangan aplikasi web modern. Keahlian utama saya meliputi:

  • Frontend: React, Next.js, TypeScript, Tailwind CSS.
  • Backend & Sistem: REST API, integrasi arsitektur, Nginx & Linux VPS.
  • Data: Data Analytics & visualisasi data interaktif.
  • Desain: UI/UX Engineering — antarmuka rapi, cepat, dan responsif.

.

Fokus & Kontribusi

Saya membangun dan mengelola TillRea sebagai galeri web pribadi: satu server melayani banyak situs lewat subdomain — dari website usaha lokal, situs demo, hingga pameran tamu yang dideploy otomatis. Fokus saya adalah sistem yang efisien, terukur, dan mendukung pengambilan keputusan berbasis data.
