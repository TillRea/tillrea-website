Tentang Pembuatnya

Halo, saya Fikri 👋

Saya mahasiswa Sistem Informasi yang berfokus pada antarmuka web modern, integrasi arsitektur sistem, dan eksplorasi data interaktif. TillRea adalah cara saya mendokumentasikan perjalanan itu — bukan sekadar daftar tautan, tapi galeri hidup tempat setiap proyek benar-benar bisa dibuka dan dicoba.

Semua situs di museum ini berjalan di atas satu server yang sama, dikelola lewat panel kurator dan bot deployment otomatis — dari situs toko penjahit lokal sampai pameran tamu dari pengunjung lain.

React & Next.js Data Analytics UI/UX Engineering Arsitektur Sistem Otomasi & Deployment

Cepat & Ringan

Satu server melayani banyak situs sekaligus — tiap pameran tampil sebagai subdomain mandiri yang ringan dibuka.

Terkelola & Aman

Kurator mengelola seluruh koleksi dari satu panel ber-PIN — publish, perbarui, dan arsipkan situs tanpa ribet.

Terbuka untuk Tamu

Hosting Gratis

Punya website? Pamerkan di sini, gratis.

TillRea membuka ruang untuk karya orang lain. Situs statismu bisa live di subdomain namamu.tillrea.my.id — tanpa biaya, tanpa ribet server. Cukup chat bot Telegram kami, kirim file situsmu, dan tunggu persetujuan kurator.
