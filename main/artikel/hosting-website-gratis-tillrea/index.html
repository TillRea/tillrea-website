Hosting Website Statis Gratis di TillRea Lewat Bot Telegram

Oleh Fikri Hikam A. • 9 Oktober 2026 • 4 menit baca

Punya website statis — portofolio, profil usaha, atau proyek belajar — tapi belum punya tempat untuk menampilkannya online? TillRea menyediakan hosting gratis dengan alamat subdomain namakamu.tillrea.my.id. Prosesnya tidak lewat panel yang rumit, melainkan cukup lewat chat dengan bot Telegram @TillReaVPS_bot.

Apa yang Bisa Dihosting?

Layanan ini khusus untuk website statis: situs yang dibangun dengan HTML, CSS, dan JavaScript — termasuk hasil build dari framework seperti React atau Vite selama bentuk akhirnya berupa file statis. Contoh yang cocok: portofolio, landing page usaha, profil komunitas, dan situs dokumentasi.

Yang tidak bisa dihosting di sini adalah aplikasi yang butuh proses di server, seperti website berbasis PHP atau yang memerlukan database dan login server-side. Situs seperti itu membutuhkan jenis hosting yang berbeda.

Langkah-Langkahnya

  1. Siapkan file ZIP situsmu. Pastikan ada file index.html di dalam ZIP — boleh langsung di akar ZIP atau di dalam satu folder pembungkus.
  2. Chat bot Telegram TillRea di @TillReaVPS_bot dan kirimkan file ZIP-nya. Nama subdomain akan diambil dari nama file ZIP-mu, jadi beri nama file sesuai subdomain yang kamu inginkan.
  3. Tunggu peninjauan admin. Setiap pengajuan diperiksa dulu oleh admin TillRea. Langkah ini menjaga agar hanya situs yang layak dan aman yang tampil.
  4. Situsmu live. Setelah disetujui (di-ACC), situsmu otomatis terpasang dan bisa dibuka di namakamu.tillrea.my.id — lengkap dengan HTTPS.
  5. Masuk Ruang Pameran. Situs yang disetujui juga tampil sebagai Pameran Tamu di lobi tillrea.my.id, jadi bisa ditemukan pengunjung museum.

Contoh yang Sudah Live

Layanan ini bukan sekadar janji — jalur pengajuan lewat bot sudah terbukti berjalan ujung ke ujung. Situs cpi.tillrea.my.id adalah contoh Pameran Tamu yang masuk lewat bot Telegram, lolos peninjauan admin, dan kini tampil di Ruang Pameran TillRea. Sementara itu Reny HikZar Collection menunjukkan bagaimana sebuah usaha lokal memanfaatkan subdomain TillRea sebagai rumah digital resminya.

Kenapa Gratis?

TillRea adalah proyek personal yang dikelola Fikri Hikam A. sebagai museum digital. Membuka ruang untuk karya orang lain memang bagian dari konsepnya: museum akan terasa hidup kalau isinya beragam. Selama kapasitas server pribadi yang menjalankannya masih mencukupi, layanan ini disediakan tanpa biaya — sebagai cara membantu pelajar, kreator, dan UMKM tampil online tanpa harus lebih dulu memikirkan biaya server dan domain.

Tertarik mencoba? Siapkan ZIP situs statismu, lalu sapa botnya di t.me/TillReaVPS_bot.
