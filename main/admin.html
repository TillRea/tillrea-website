Situs langsung tampil di lobi utama setelah publish.

Syarat ZIP

  • Berisi situs statis (HTML/CSS/JS/gambar).
  • index.html di root ZIP, atau di dalam satu folder pembungkus.
  • Ukuran maksimal 50 MB.

Aturan Nama

  • Huruf kecil, angka, dan tanda hubung saja.
  • Nama cadangan tidak bisa dipakai: n8n, www, api, admin, mail, ftp.

Update Situs

  • Publish dengan nama yang sama = isi lama diganti total dengan ZIP baru.
  • Bisa juga dari tab Situs Live, klik tombol Update pada situsnya.
  • Semua publish tercatat otomatis di riwayat git server.
